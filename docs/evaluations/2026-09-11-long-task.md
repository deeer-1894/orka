# 长复杂任务复测：2026-09-11

## 方法与边界

基线代码为 `feat/layered-context` 的 `3513ebc5ebf5a6f6928b6cde33ae6ff393d9bc33`。修改仅位于 `codex/long-task-optimization`。前端使用同一构建，后端本地运行，工具服务运行在 Docker。

三次使用[同一中文任务描述](long-task-prompt.zh-CN.md)，仅替换测试编号和输出目录。任务要求比较 Eino、LangGraph、CrewAI、AutoGen，实际读取不少于十二个官方页面；生成 3,600 条有效工单、36 条重复记录和四条分别仅有一处错误的记录；清洗、统计、生成三张 SVG 和 HTML；实际运行验证，并交付来源、报告、复现说明、校验清单和 ZIP。

模型均为 `deepseek-v4-pro`，辅助模型为 `deepseek-v4-flash`，关闭多智能体模式。新功能中对子任务工具可见性和上下文保护的验证使用真实 Eino 编排器与可控模型测试，不把单智能体在线复测作为多智能体性能证据。模型输出具有随机性，本次是一组个案复测，不代表普遍成功率或性能提升比例。

## 独立验证方法

验证器不导入或执行任务生成的代码。它依据原始公式重新构造全部记录，逐字段对比 CSV，独立计算总体及 42 个分组的均值、nearest-rank P95、满意度、重开率和包含等号的 SLA；检查 CSV 表头及每行列数；最后核对来源与实际网页读取证据、SVG/HTML、文件清单和 ZIP。任务生成的 `verify.py` 结果与这份独立审计分别报告。
