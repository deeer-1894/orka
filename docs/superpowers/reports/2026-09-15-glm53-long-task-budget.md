3. **不满足指定启动语法**：用户要求 `serve --host ... --port 0 --db PATH`，代码只接受全局 `--db` 放在子命令前，按原要求运行退出码 2。

## 平台剩余问题

- **目录交付约定冲突（尚未修复）**：模型将 `outputs/ledgerdock` 目录加入不可删除的交付要求，检查器只接受非空普通文件，最终检查被目录阻塞并标记 partial。需要明确支持目录的结构检查语义、遍历预算、空文件/测试夹具规则及链接展示，再实现，不应直接忽略失败或清空原始交付要求。
- **计划重复（已补提示，仍需真实复测）**：压缩后生成了 pkg/pack/s5 等重叠步骤，最终累计 18 个条目。后台应保留原始义务；仅依靠标题模糊去重可能误删不同要求，不宜采用。
- **业务验收同源错误（尚未消除）**：即使换用 Decimal，仍可复制同一个错误业务假设。需要对原始需求的边界反例做独立验收，不能将结构检查当作语义正确证明。
- **超时用量缺失（尚未修复）**：缺少终止 usage 时可能记录 0，不能据此准确衡量真实供应商消耗。
- 本轮为平台压力测试，生成的 LedgerDock 尚未达到原始需求的完整验收标准；不将其作为可直接上线项目交付。
