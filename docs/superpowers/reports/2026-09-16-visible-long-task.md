## 本分支修复

1. 用量准入错误原先统一显示为模型输出/时间超限。现在按错误链区分任务预算不足、每日配额不足、用量记账失败；保留不自动重试及取消优先级，不放宽预算检查。
2. 历史确认卡的点击结果只存在组件内存中。现在根据当前会话的后续运行/终态记录判定失效，刷新不再把已继续执行的旧确认当作待处理；同一轮并行工具完成不会误判该确认失效。
3. Python 工具描述明确每次执行的 `/tmp` 和内存不持久，要求跨调用脚本、解压目录和中间结果放在会话工作区相对目录，避免反复丢失验收副本。

任务生成产物另外经过纠正：修复了幂等/回滚测试语义冲突，补齐漏打包的验收脚本，以及文档对 TAB/CR 处理的错误描述。产物属于会话工作区，不混入应用源代码。
