# USGS 真实地震数据离线分析台

请完成一个可以实际使用的“USGS 最近七天地震观察台”，用于查看官方记录的数据分布，不做地震预测或人身安全建议。

1. 确认当前日期，从 USGS 官方 https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/4.5_week.geojson 获取真实数据；保存完整原始响应、来源 URL、UTC 抓取时间。区分震源发生时间、记录更新时间和抓取时间。若请求失败如实说明，不用虚构数据填补。
2. 用 Python 标准库实现可离线复跑的小项目，分离读取/校验、规范化/统计、页面渲染、命令入口。从保存的证据生成 earthquakes.json、earthquakes.csv、dashboard.html。记录官方事件 ID、发生时间 UTC、震级、位置描述、经纬度、深度、事件类型、官方详情链接；缺失值保持未知，不转成 0。去重按事件 ID，遇到重复保留更新时间较新的记录，记录排除与质量问题。只将真实地震事件计入统计，不把其他类型混进来。
3. 输出一份简短中文 report.md，给出有效事件数、震级中位数、按 UTC 日期分布和浅层/中深层/深层分布（深度<70、70至<300、≥300千米）；缺失深度单列，分组总数应能回到总体数。说明观测范围和数据局限，不能把最近七天清单当完整地震风险评估。
4. dashboard.html 是单文件离线页面，样式、脚本、数据全部内嵌，不依赖本地服务器或外部资源。支持位置关键词搜索、最小震级筛选、发生时间正反排序、清空筛选，显示匹配条数和当前筛选结果的震级中位数。组合筛选应一致，无结果时显示明确空状态，中位数显示“无数据”而非 0。
5. 为日期、重复记录、缺失值、筛选边界、统计一致性和输出一致性编写至少16项有意义的自动测试，真实执行并保存输出。实际打开生成的 HTML，操作搜索、震级筛选、排序、组合条件及清空按钮，记录可观察结果；页面打不开先检查已有能力和文件路径，不反复猜绝对路径或复制整页内容。测试失败要定位修复；尚未验证的内容明确列出。
6. 交付 earthquake-dashboard.zip（源码、原始证据、README、报告、数据、页面、真实验证日志），以及可单独预览的 dashboard.html、earthquakes.csv、report.md。按 README 原样命令从最终ZIP新解压构建和测试；说明哪些检查实际通过、哪些尚未验证。代码结构保持清晰，不为了凑测试数写重复断言，不扩展部署服务。

全程自主执行，不需要我选择具体工具，不注册账号，不对外发送消息；不要编造来源、抓取数据或执行结果。
