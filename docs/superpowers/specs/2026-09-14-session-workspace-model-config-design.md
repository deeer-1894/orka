# 会话工作区、文件预览与模型配置设计

## 目标

为每个会话建立独立文件工作区，让文件浏览和预览只展示当前会话内容；增加文件夹导航、CSV 表格预览和代码高亮；提供可编辑的多厂商模型配置；移除预算耗尽后的“重新执行（从头开始）”入口，保留刷新/重新生成入口。

## 数据与隔离

会话工作区使用用户根目录下的会话目录：`{userRoot}/sessions/{conversationID}/`。创建会话时确保目录存在，文件读、写、列举、预览、下载和删除均从当前认证用户与当前会话解析工作区，禁止客户端通过路径参数切换到其他会话。历史数据库中的运行记录、消息、检查点和事件清理一次；用户账号、配置和已有文件保留。

## 文件面板与预览

文件接口返回当前会话目录的相对路径、类型、大小和更新时间。前端将文件夹作为可点击节点，维护当前目录并支持返回上级。文本类文件采用安全的等宽代码预览并按扩展名选择高亮语言；CSV 使用表格预览，限制单次读取的行列和字节数，超限时显示截断提示。未知二进制文件继续提供下载或已有预览能力。预览内容必须由当前会话文件接口返回，不能直接拼接任意路径。

## 模型配置

前端提供厂商预设、自定义厂商、Base URL、API Key 和有序模型列表。依据用户最新确认，模型选择只保留 Auto 和手动模型名称，不再使用主、次模型分级。Auto 使用列表首项；手动选择固定使用指定模型，不自动升级。前端支持列表排序和手动填写模型列表。后端保存配置时按用户归属，API Key 只允许写入和脱敏读取，列表和运行记录不得返回明文密钥。模型列表优先调用厂商兼容的 `/models` 接口；失败时允许手动填写模型名。请求运行时使用会话选定模型，并校验 Base URL、模型名和用户配置归属。首期以 OpenAI 兼容协议为统一适配层，预设常见厂商只提供默认地址和字段提示。

## 交互变更

删除预算耗尽页面中的“重新执行（从头开始）”按钮及对应文案，保留刷新/重新生成小按钮。部分完成的任务继续显示已保存进度和文件，用户可以在当前会话发起新的刷新请求。

## 验证

后端测试覆盖会话目录创建、路径越界、跨会话读取拒绝、模型配置脱敏和模型列表失败回退。前端验证文件夹导航、CSV 表格、代码预览、刷新入口和模型配置表单。使用测试账号 `real@test.com` 验证注册、登录、两个会话之间的文件隔离，以及模型配置的保存和脱敏展示。
